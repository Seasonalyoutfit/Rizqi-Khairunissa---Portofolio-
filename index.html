Rizqi Khairunissa

Halo! Saya perintis SeasonalyOutfit yang baru berjalan sejak awal September 2026. Kecintaan saya pada dunia mode mendorong saya membangun ruang kurasi ini untuk belajar dan membantu orang lain menemukan gaya terbaik mereka.

Saya berfokus sebagai kreator di balik layar—bukan model—yang mengkurasi produk dan menyusun rekomendasi visual yang estetik. Dalam prosesnya, saya memanfaatkan teknologi AI sebagai asisten produktivitas sembari terus belajar menguasai tools kreatif secara otodidak.

Dengan latar belakang lulusan SMK Infokom Bogor (Rekayasa Perangkat Lunak, 2018) dan impian untuk traveling memperluas wawasan mode global, saya berkomitmen untuk terus bertumbuh di industri kreatif ini.
